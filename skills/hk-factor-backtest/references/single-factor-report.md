# 通用单因子可视化模板

用户指定的HTML只作为视觉与交互参考，不是实验数据模板。所有新单因子报告复用纸白青绿配色、横排统计、横向页签、收益主图、密集表格及详情页；不得固定三组实验、作者、因子清单、日期、阶段、持有期或历史数值。

实际入口为 [通用页面](../assets/single-factor-generic/dashboard.html)，资源见 [模板清单](../assets/single-factor-generic/template.json)。空模板不含实验数据。按照 [数据接口](single-factor-data.md) 将本次引擎输出映射为JSON，再运行 `python <skill>/scripts/render_single_factor.py --data <本次JSON> --output <本次结果目录>`。

渲染器只负责展示，不计算收益、不替代引擎。六页签为收益对比、入选因子、全部单因子、相似度矩阵、实验档案、方法与检验。所有筛选和评估设置来自输入，单批不强加来源选择，多批不限数量；缺失时显示空状态。

详情展示排版公式、实际参数、计算口径与经济含义假设，基础公式与定向分开。收益图支持多因子同图、持仓切换、线性/对数、图例控制；组数和年度来自本次结果。下载交付完整指标、逐日数据与检验。新计算遵循主技能，旧报告明确重建时保留当批口径。多因子使用独立模板。

模板不依赖历史三组目录，资源随新报告复制。检查数据引用、序列长度、指标和年度连乘、公式覆盖、下载可用性；实际浏览器验证空模板和无关因子输入，覆盖切换、搜索、下钻及窄屏。模板验证不等于回测通过。旧的三批快照已退出默认技能，只在本地工作归档保留以便追溯。
