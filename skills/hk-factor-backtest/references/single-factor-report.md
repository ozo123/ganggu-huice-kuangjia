# 单因子报告默认模板

视觉基准采用用户更正后的 `output/LLM基本面时点研究-2026-0926-回测结果/backtest/dashboard.html`。复用纸灰背景、青绿与砖红配色、衬线标题、横向页签、总览散点与侧栏统计、相关矩阵和单因子多图布局。基础 `dashboard.css`、`standalone.css` 与该参考逐字节一致，数据接口扩展另放 `report-layout.css`。多因子继续使用独立TA-Lib模板。

用户要求只制作展示，不区分因子好坏。默认三页签为 **总览、单因子、全部因子**，不设置“好因子”“无效因子”“入选”“剔除”页面、分组或榜单。所有输入候选可查，只显示已有回测、待补定义或数据、未开仓、计算失败等计算状态；不因IC、收益或原筛选结论隐藏因子。原始筛选文件作为证据保留，不用于展示分流。

入口为 [dashboard.html](../assets/single-factor-generic/dashboard.html)，来源与哈希见 [template.json](../assets/single-factor-generic/template.json)。模板不含参考实验的数据、作者、因子、日期、PIT规则或业绩；所有内容来自本次输入。

## 实际生成入口

内置 `run.py run/report` 的 `standalone_report.publish` 通过 `single_factor_from_state.py` 映射已保存结果，调用共享渲染器。历史阶段、持有期、定向和指标保留原值。旧报告实现仅保留为 `publish_legacy` 追溯；展示适配不表示旧交易引擎已通过20日新账本验收。

其他引擎按照 [数据接口](single-factor-data.md) 导出本批JSON后执行：

```powershell
python <skill>/scripts/render_single_factor.py --data <本次report-input.json> --output <本次结果目录>
```

新目录由项目标准入口管理。用户明确重建旧报告时，先备份旧页面与资源，再替换指定目录的展示文件；原始数值与验证文件保持原样。不要在每批输出中临时改写模板JS。

## 页面行为

总览展示当前设置的 Rank IC × 算术年化多空净收益散点、同实验/阶段/方向的各复权与持有期中位数、完整因子表现表、相关性矩阵及IC窗口。缺少算术年化收益时标缺失，不能拿CAGR替代。相关性为有正负号的红—白—青色阶[-1,1]，保留实际计算方法、有效月份与共同证券数；原Spearman结果不能重标Pearson。邻近因子按相关系数绝对值展示。

实验、阶段、方向、复权、持有期等控件来自 `meta.dimensions` 和 `contexts`。参数版本独立保存，可查看原选定版本或全部参数网格；这是版本选择，不是因子好坏分类。同一因子的多个版本不能合并。展开收益曲线后可切换多空/最高组、线性/对数、图例、缩放、图片导出；持仓切换同步曲线、指标与年度收益。

点击散点或名称进入单因子详情，保留对应设置与参数版本；切换详情设置同步顶部控件。展示MathML公式、参数、定义缺口、计算口径、经济含义假设、原IC与方向乘数、净值与回撤、完整分组净值和年化收益、分组波动、持有期比较、IC分布、每日/累计IC及年度收益。缺失序列保持缺失，不挪用其他设置曲线；未开仓不画伪造的平直业绩。

全部因子按输入完整保留，支持名称/公式/经济含义搜索及计算状态过滤。研究笔记在实验档案单列，不计为因子。下载链接交付本批完整指标、逐日账本和检验依据。

## 验收

渲染器在替换页面前预检唯一ID、上下文、方阵、有限数值、本地引用、日期和序列长度。逐日大数据通过本地JS分片按需加载，支持双击HTML离线查看。模板、数据与分片一起保存。

在scripts目录运行 `python -m unittest test_single_factor_template test_formula_display`。以真实保留数据核对映射值和源文件哈希；用浏览器检查三页签、设置与参数切换、表格排序、搜索、详情、缺失数据、相关矩阵、空模板、无关因子和窄屏。实际截图目视验收。`template-render-verification.json` 仅证明展示输入与引用校验，不替代回测数值回执。
