# 每日滚动账本与回归验收

适用于单因子和多因子的开盘入场、收盘到期组合，以及已有结果的持仓/资金修复。这里的 H 是持有期限，不是可永久占用的现金席位。现金分红与红利再投采用各自权益账本；下述时序、资金复用和检验原则共同适用。

## 时序与资金预算

默认 H=20 个市场交易日。信号 t 收盘产生，入场日 e=t+1 开盘交易，到期日 e+20=t+21 收盘计划退出。收益标签也是 t+1 开盘至 t+21 收盘；末 H+1=21 个信号日的未成熟标签留空。21 是信号至到期的索引偏移与盘中批次数上限，持有期限仍为20日。

单因子回测及多因子训练均只用2010-01-01至2022-12-31。信号、入场及标签到期日必须在该区间，训练末尾21个市场交易日位置的未成熟标签清除，不借用2023年收益。单因子期末持仓按2022年最后交易日估值，不能延长回测去等到期退出。冻结组合的2023–2025测试独立启动，测试结果不回流到训练、定向或筛选。

每个市场交易日先用前收盘已结算的自有现金决定开盘交易，再计入盘中损益、收盘到期退出、费用和风险减仓。当天收盘才取得的退出资金不能用于当天开盘。开盘新批与当日收盘到期的老批短暂重叠，正常批次盘中至多 H+1、日终至多 H；超过计划期限的残仓另记，不混入正常未到期批数。

默认新批次目标毛预算为前收盘 NAV/(H+1)，H=20 时为 NAV/21。实际成交额须同时满足：已结算自有现金足以支付多头本金及全部开仓费用，卖空所得不作为新增资本，开盘已有毛敞口加新仓不超过扣费后的净资产。没有可成交股票或预算不足时保留现金并记录原因，不为了“每天开仓”注资、借用未来退出款或制造成交。若用户指定另一种资金分配方式，保留其要求并验证上述自融资与时序约束，不能静默替换持有期限。

保存目标预算、实际开仓金额和开仓费用；未用毛预算 = max(目标预算−实际开仓金额−开仓费用, 0)。包括整日未开仓与部分未成交，不能把未成交股票的预留金额算成已投入。

## 停牌残仓与现金复用

到期时只退出当时可成交的证券。已经退出的部分，其结算后自有现金在下一开盘可用于新批次；不等待同批最后一只停牌股退出。将未退出证券的股数、原到期日、成本/权益、封存卖空所得和估值状态单独保存，释放正常批次的调度席位。即使聚合存储残仓，也要能追溯到期来源。

残仓继续按可得估值计入资产、负债和毛敞口，恢复交易后按实际可成交时点处理。不能删除残仓、填0、按无交易的旧价假定平仓，也不能把同一股票的多头和空头残仓净额抵销后低报毛敞口；不同方向与相应封存所得分开核算。

风险约束造成减仓时按实际成交额计费，余仓保留到期规则。持仓无法交易导致的敞口超限或现金不足须单独披露；不能通过截断指标宣布约束已满足。多空账户中保留的担保现金与闲置资金不同，应同时展示自有现金、封存卖空所得和实际毛敞口。

严格开盘可成交性须有对应数据支持。只有日线正成交量的历史实验只能称为全天可交易代理，不能称已验证开盘可成交。兼容复核这种历史实验时记录代理字段及限制；数值核对通过不等于验证了集合竞价流动性、借券或成交容量。任何情况下不按未来退出收益/标签是否存在提前删掉交易成员。

## 账本字段与恒等式

保存完整逐日日期、净值、日收益、多头市值、空头负债、自有现金、封存卖空所得、开仓/退出/风险减仓成交额与费用、市场损益；另保存新开批次数、正常未到期批数、延期多空金额与条目数、开盘净资产与毛敞口、目标/实际/未用预算、未成交条目及未开仓原因。原始逐股/逐批持仓或可重放的成交记录与分组、价格、估值状态应可追溯。

逐日复核：净资产 = 自有现金 + 封存卖空所得 + 多头市值 − 空头负债；毛敞口 = 多头市值 + 空头负债；本日净资产 = 前日净资产 + 期间权益损益 − 实际费用。现金分红账本还应包含应收分派和实际到账的对应变动，应收不能当作已经到账的开仓资金。内转资金必须两边同步记账。净费和独立零费账本各自检查，指标从各自完整净值重算。

## 修改账本时的最小回归集合

1. 恒价、可成交且每天有信号的合成样本：每天均能形成新批次；首批在 e+H 收盘退出，H=20 时信号0对应入场1、退出21；日终正常批数≤20、盘中≤21。无费用时财富不变。
2. 到期批次仅一只股票停牌，其余正常退出：停牌股的股数/权益继续保留，其他股票释放的资金仍能支持后续开仓。不能仅检查净资产恒等式；错误锁住整批现金的账本也可能满足恒等式。
3. 开收盘不等的可手算样本：核对入场日开盘到收盘损益、费用及到期索引；确认开盘预算未提前借用当天收盘退出资金。覆盖只多与多空、净费与零费。
4. 同股不同批次、不同方向的延期持仓：核对毛敞口与封存所得不被错误净额抵销。部分未成交、整日未开仓时，未用预算与实际成交相符。
5. 用独立实现（如动态持仓列表）或可手工重放的现金流样本对照生产账本，再在实际训练/测试及各选股方式上核对现金、净值、费用、正常批数、敞口和开仓覆盖。独立实现不调用被测撮合/资金内核。
6. 从完整逐日序列独立重算 CAGR、Sharpe、最大回撤与年度收益；保留真实尚未解决的超限和数据限制，不用旧回执或固定“通过项目数”替代本批检验。

## 已有结果的修复与交付

先确定请求范围。仅更新 skill 的默认周期或模板时，只修改规范与模板资产，不执行回测、不改历史结果的周期标签。实际获授权修复持仓和资金时，冻结已确认因子清单、预处理、特征列序、训练方向、模型和预测；哈希核对模型/预测，数值核对 IC 不变。净费/零费交易账本、费用、绩效和年度收益重新计算。若获授权改变计算周期、标签、信号或特征，则按依赖关系扩大重算并明确说明。

新数值结果保存为独立来源批次，旧结果留作追溯。对比实际开仓日、平均毛敞口、正常批数、延期残仓与现金变化，确认修正解决了原问题，而不只证明公式自洽。报告按 [TA-Lib 模板与页面验收](standalone-report.md) 提供可下钻的逐日滚动检查；数值与浏览器验收完成后再更新用户入口。技能流程更新只能称规范更新，不能称尚未修改的内置引擎已通过这些检查。
