# 港股标准化单因子与多因子组合回测

规范版本：2026-09-29.train2010-2022-rolling20-single-template-v7。默认持仓期为 **20 个市场交易日，每日滚动**，适用于单因子和多因子；其他周期只在用户要求时执行。用户本次明确要求优先；指定历史结果的因子清单、持仓期、复权口径和模型范围应保留。只更新 skill 时不重算历史结果，也不把历史报告改标成新周期。

**时间边界：单因子回测与多因子训练均仅使用 2010-01-01 至 2022-12-31。** 单因子的收益、IC、定向、分组、相关性去重及筛选都在该区间；多因子训练的信号、入场和标签到期日也必须全部在该区间。2023-01-01至2025-12-31只用于冻结模型后的组合测试，不进入单因子回测、筛选、调参或拟合。不能因为行情覆盖更长、默认“全历史”或复用旧结果而自动扩展时间范围。

输入是**用户给定的因子定义和数据路径**。完成日线可计算性判断、所选设置回测、定向、筛选与离线报告；未限定时执行20日、现金分红与红利再投两个设置。不触发检索、挖因子或上游库写入。`quant-video-factor-library` 只可作为用户主动选择的一种定义来源。

## 使用入口

单因子已有入口为内置 `scripts/run.py`。本次更新的是执行规范与模板，不代表旧引擎已实现20日默认值、新账本或多因子入口：当前内置账本仍有收盘入场路径，旧周期常量、相关性和报告也须核对。正式运行前按本规范完成能力检查、必要适配和数值验收；不得只加配置或改标签即宣称合规。多因子须提供本次指定且经过检验的入口，不默认执行历史批次脚本。

```powershell
& '<Python>' '<skill目录>/scripts/run.py' inspect --data-root '<用户日线目录>' --factors '<因子定义.json>' --output '<结果目录>'
& '<Python>' '<skill目录>/scripts/run.py' run --data-root '<用户日线目录>' --factors '<因子定义.json>' --output '<结果目录>'
```

适配完成后的 `run` 应自动完成检验与报告；`report --output ...` 重建页面；`verify --output ...` 复核数值。单因子配置明确 `start=2010-01-01`、`end=2022-12-31`；多因子配置将单因子区间、训练区间和冻结测试区间分开，不能把行情总截止日当作拟合截止日。示例见 [单因子配置](assets/example_config.json)、[多因子流程配置](assets/example_multifactor_config.json)、[因子定义](assets/example_factors.json)。依赖见 `scripts/requirements.txt`；Python解释器由本次环境或用户指定，不固定安装路径。

每次使用用户指定的引擎入口、因子定义文件、行情目录和来源名称；不得固定某个作者、旧批次或旧行情目录。缺少输入时从当前请求明确定位，不自动选用历史样例。

先用 `python run_backtest.py run --entry <指定引擎run.py> --factors <指定因子.json> --data-root <指定行情目录> --source <来源> --dry-run` 核对实际命令，再移除 `--dry-run` 执行。

本机使用所属项目的 `run_backtest.py` 可自动把结果保存为 `output/来源-YYYY-MMDD-回测结果`，其 --entry、--factors、--data-root、--source 均显式指定。所有收益、IC、净值、回执和报告只保存于回测项目的 output，不写回视频或LLM研究目录。

## 执行流程

1. 读取 [输入契约](references/standalone-inputs.md)。把给定公式、参数、方向、时点和必要字段写成 JSON。先判断能否仅靠现有日线计算；不存在的分钟、逐笔、财务、资金流或新闻输入不可用价格代理冒充。核心定义缺失单列；定义完整的新公式继续实现，不因不在示例里就判不可回测。
2. 表达式可直接运行；复杂公式写确定性本地 Python `compute(fields, parameters)`。先审阅再执行，保留公式和代码。运行 `inspect`，核查缺失字段和复权模式；不可回测项也留在整批记录中。
3. 先检查入口是否实现本规范，再执行 `run`。涉及滚动持仓、成交或资金修复时必读 [滚动账本与回归验收](references/rolling-execution.md)，先用合成样本检查时点和停牌残仓现金复用，再运行真实组合。数据只读，面板与结果写入输出目录；缓存按源文件、配置、实现与引擎指纹隔离。量额不复权；按本次所选后复权口径分别计算。官方上市日期未提供时披露首次有效成交六个月代理，不称真实上市日。
4. **用户要求的 IC 翻转是默认规则**：仅在2010–2022规定区间内，对每个复权口径、每个持仓期的已成熟标签计算原平均 Rank IC；为负则乘 −1，再重建分组、重跑该设置组合。不能只改 IC 符号或交换已算好的收益。保留原 IC、翻转乘数和定向后 IC。“全样本定向”只指该训练区间内的事后诊断，不能扩展到2023年以后，不能包装为样本外策略。
5. 全部给定因子先回测，再按 [筛选规则](references/standalone-methodology.md) 做相关性去重、IC 门槛检验。各个已运行设置分别归类，不取其中最佳作为全局结论。用户指定冻结因子库时保留其清单及当批相关口径，不按新的默认口径擅自重选。失败、常数、低覆盖和无法回测均展示原因，不当成 0 收益。
6. 自动生成 `dashboard.html`，按 [统一报告模板](references/standalone-report.md) 验证相应页签和已计算设置的切换。**所有单因子报告默认使用用户指定的“视频三组合并-2026-0929-回测结果/dashboard.html”模板**，必读 [单因子报告规范](references/single-factor-report.md) 和 [单因子模板快照](assets/single-factor-20260929/template.json)。多因子组合继续使用 [TA-Lib双因子库模板](assets/talib-20260928/template.json)。先读取对应页面、样式和交互，再接入本次数据；不能另做侧栏布局代替。交付完整逐日账本、页面、`verification.json`、筛选表和指标 CSV；数值检查与浏览器检查均通过后更新结果入口。仅修改技能说明时无须重算整批因子；修改计算/报告代码则运行相应回归与真实样本验收。

## 多因子组合流程

执行组合任务必读 [双因子库与模型规范](references/multifactor-workflow.md)。先在2010-01-01至2022-12-31完成全部单因子回测、Pearson去重（1号库）、定向Rank IC门槛筛选（2号库），再仅在同一区间训练Ridge与LightGBM。H=20时入场为t+1、标签到期为t+21，凡到期超过2022-12-31的训练样本及IC样本均剔除，不借用2023年收益补齐。2023-01-01至2025-12-31只作冻结组合测试；测试期因子值可作为冻结模型的当日输入，但不另做单因子回测或反向影响训练与选库。

默认单因子与组合均为H=20。默认模型矩阵为每口径2库×2模型×2选股方式×2持仓方式=16策略，双口径共32；用户指定部分库、模型或复权口径时，仅输出实际集合，不补造未训练的策略。模型数及曲线数动态计算。用户要求多个H时，每H独立训练与冻结。只做多为最高组或最高20只；不存在“只做多中的多空组”。

只修复交易账本、资金复用或报告时，保持已确认因子清单、预处理、模型文件、方向、预测和IC不变，以哈希与数值对照核验；重新计算受影响的净费/零费账本、指标与年度收益，保存为新结果批次。若修复确实改变标签或信号，则明确扩大重算范围，不能继续声称模型与IC未变。

## 公式展示
所有新报告及旧报告重建，都在单因子详情标题旁展示已排版的公式、实际参数和计算口径，随因子切换同步更新。使用原生 MathML 或随包提供的离线公式渲染器，不把 LaTeX 源码直接作为公式展示。附经济含义推测并明确其假设性质。展示字段及旧报告补充方式见[输入契约](references/standalone-inputs.md)。基础公式与IC方向翻转分开说明，不以文件路径代替计算方法。

## IC 缩尾与版本

新运行自动使用下述 winsorize 口径；配置、因子 payload 和代码指纹均记录它，旧未缩尾回测不得直接改标签冒充新结果。单因子及训练IC仅使用2010–2022区间内已成熟样本；冻结模型的测试IC单独记录，不回流到方向、筛选或拟合。

## 固定规则

- 上市满 **6 个自然月**；t−4…t **5 个市场交易日原始成交额均值严格 > 3,000,000 港元**；完整窗口，已知 0 纳入、未知不补，当前可交易。
- **20组、20日持仓**，并列平均秩不拆分。信号t收盘，t+1开盘入场，t+21收盘到期；每日调度新批次，已结算现金共享复用，到期停牌残仓独立管理。开盘/收盘错位下盘中最多21批正常仓位、日终最多20批；默认日预算为前收盘净资产/21，同时受已结算现金、开盘敞口和费用约束。21批是资金调度容量，不是持有期限，详见 [滚动账本](references/rolling-execution.md)。
- 多头和空头担保各半、卖空所得封存；所有实际买卖及风险减仓**单边20bp**；日终扣费后毛敞口≤净资产100%。无可成交份额留现金。
- **后复权现金分红 / 后复权分红再投**分别执行。现金用股数与分派账本，不能直接对加性现金后复权价取百分比收益。
- IC 计算默认按每日、每持仓期的共同有限股票截面，对因子值和未来未扣费收益分别进行 1%/99% 分位数 winsorize（线性分位数，替换尾部而非删除股票）；至少20只。Pearson 使用缩尾后的值，Rank IC 在缩尾后重新计算平均秩。缺失保持缺失，常数截面 IC 不可定义。方向翻转、ICIR、HAC t、累计IC和0.01筛选均使用该IC。缩尾只影响IC评估，不直接修改分组信号、因子间相关性、实际收益或费用；IC定向变化仍会触发组合重跑。分位数仅来自当前截面，不跨日期拟合。 另报Pearson、ICIR、HAC t。毛夏普来自独立零费账本；净夏普来自扣费账本，年化252、无风险率0。
- 月末截面直接以原始因子值计算Pearson相关性，取有效日期等权平均；不先排名，不套用IC缩尾；**|ρ|>0.8**建冲突图。动态最小度多起点贪心及1换2改善，尽量多保留；不声称全局最大。先去重，再剔除**定向后平均Rank IC<0.01**，恰好门槛保留。

现金账本、停牌、公司行动和样本边界随报告保留，见 [完整口径](references/standalone-methodology.md)。不要把旧实验回执套到新样本。

## 解耦与历史兼容

挖因子skill只负责采集、审阅、入库和定义导出，不再自动回测、处理回测实现队列或更新报告。本机 `backtest_bridge.json` 已停用。需要回测时独立调用本skill，可用普通JSON或将库中选定定义转为本输入契约。

本机旧 `scripts/pipeline.py`、`assets/local_config.json` 和旧参考文件仅保留历史兼容，不随独立包分发；它们不属于独立入口，不在新任务默认执行。历史报告、注册表、源证据均保留；不为解耦新建或修改定时任务。
